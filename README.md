## ⚡ Key Features

- **🚀 High-End Performance**: Optimized WebGL & Canvas components running at a buttery-smooth 60 FPS.
- **💎 Premium Aesthetics**: Curated neon-dark design system with glassmorphism and motion at its core.
- **📦 Zero-Config Integration**: Seamless copy-paste workflow for React, Vite, and Next.js projects.
- **📱 Fully Responsive**: Every element is engineered to scale perfectly from ultra-wide monitors to smartphone viewports.
- **🛠️ Developer-First DX**: Clean, readable TypeScript code with logical prop structures.

## 🎨 Component Library

UI HUB features a wide range of interactive elements categorized for easy discovery:

| Category | Description | Key Components |
| :--- | :--- | :--- |
| **Backgrounds** | Cinematic, full-screen interactive environments. | Space, Black Hole, Warp Speed, Stripe Mesh, Neural Network. |
| **Cursor Effects** | High-precision interactive mouse followers. | Aurora, Magnetic, Target, Black Hole, Heart. |
| **UI Elements** | Interactive, animated buttons and cards. | Orbit Button, Corner Border Button, Magic Card, Floating Pill. |
| **Animations** | Sophisticated text and logic-driven motion. | Pixel Text, Glitch Text, Staggered revealers. |

## 🛠️ Tech Stack

Built with the latest and most performant technologies in the ecosystem:

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Motion**: [Framer Motion](https://www.framer.com/motion/) & [GSAP](https://gsap.com/)
- **3D Graphics**: [Three.js](https://threejs.org/) & [React Three Fiber](https://docs.pmnd.rs/react-three-fiber/)
- **Utilities**: [Lucide React Icons](https://lucide.dev/), [Clsx](https://github.com/lukeed/clsx), [Tailwind Merge](https://github.com/dcastil/tailwind-merge)

## 🎨 Brand Identity

UI HUB is defined by its futuristic, high-contrast aesthetic. Our design system is engineered to provide a premium "developer-core" experience.

### 🌈 Color Palette
Designed for maximum legibility and visual impact in dark mode:
- **Neon Green**: `#00FF00` (Primary Action & Accent)
- **Deep Velocity Black**: `#000000` (Primary Background)
- **Glass Transparency**: `rgba(255, 255, 255, 0.07)` (UI Containers)

### 🔡 Typography
We use a curated selection of fonts to balance technical precision with modern flair:
- **[Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk)**: Primary heading font for a versatile, geometric look.
- **[Orbitron](https://fonts.google.com/specimen/Orbitron)**: Display font used for branding and high-impact UI elements.
- **[Inter](https://fonts.google.com/specimen/Inter)**: System-standard body font for optimal readability.

### 💎 Design Principles
- **Glassmorphism**: Subtle backgrounds with heavy backdrop blurs.
- **Micro-animations**: Logic-driven motion for intuitive feedback.
- **Futuristic Dark UI**: High-contrast elements optimized for developer dashboards and modern landing pages.


## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18.x or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/jainil224/UI-HUB-
   cd UI-HUB-
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment:**
   Create a `.env.local` file by copying the example:
   ```bash
   cp .env.example .env.local
   ```

4. **Launch Development Server:**
   ```bash
   npm run dev
   ```

## 📦 Deployment

Optimized for high-performance static hosting:

```bash
npm run build
```

The production-ready assets will be located in the `dist/` directory, ready to be deployed to Vercel, Netlify, or AWS.
